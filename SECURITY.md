# Security policy

## Supported versions

Only the newest release gets security fixes.

## Report a security problem

Do not open a public issue for a security problem.

Report it privately at <https://github.com/austinfringer/TagPile/security/advisories/new>. Include:

- the TagPile version and how you run it (standalone build or from source),
- the steps to reproduce the problem,
- what an attacker can do with it.

One person maintains TagPile in their free time. An answer can take some days.
